# UnicodeFlash

一个用 Canvas 渲染的 Unicode 码位快闪 / 字体覆盖测试工具。

支持最多 256 个字体组成的回退链，毫秒级速度驱动，可自定义起始和结束码位，从本地文件加载字体（ttf / otf / ttc / woff / woff2）。

---

## 这是什么

UnicodeFlash 是一个单文件网页工具，用来：

- 快速轮播 Unicode 码位（从 `U+0000` 到 `U+10FFFF`）。
- 用你自定义的字体回退链渲染每个码位。
- 观察哪些字体覆盖了哪些字符，哪些掉到了 Last Resort 的豆腐块。

适合做：

- 字体覆盖范围测试
- 生僻字 / CJK 扩展区检查
- 字体回退链调试
- Unicode 平面分布观察

---

## 怎么用

### 1. 下载网页

下载仓库里的 `UnicodeFlash.html`。

### 2. 打开

- **iPad / iPhone**：存到「文件」App，用 Safari 或 Chrome 打开。
- **电脑**：直接双击，用浏览器打开。

也可以把网页部署到 GitHub Pages 后，直接在浏览器访问在线版本。

### 3. 添加字体

点页面下方的 **「+ 从文件添加字体」**，选择一个或多个字体文件：

- `.ttf`
- `.otf`
- `.ttc`
- `.woff`
- `.woff2`

字体加载后会自动加入回退链，排在末尾。

### 4. 调整回退链

每个字体项都有：

- `↑` `↓`：调整优先级，越靠前越先被匹配。
- `✕`：从链里移除。

最多支持 **256 个字体**。

### 5. 设置扫描范围

- **起始**：起始码位，十六进制，不带 `0x`，比如 `0`、`20000`。
- **结束**：结束码位，比如 `10FFFF`、`2A6DF`。
- **毫秒**：每个码位停留多少毫秒。越小越快，最小 `1`。
- **每段**：每跑多少个码位主动让出主线程一次，防止内存堆积。默认 `4096`。

### 6. 开始快闪

- 点 **「开始」** 运行。
- 点 **「暂停」** 暂停。
- 点 **「重置」** 回到起始码位。

## 仓库里的字体

仓库里放的字体是给用户**手动下载**后，再通过「从文件添加字体」加载的，网页不会自动加载它们。

| 文件 | 说明 |
|---|---|
| `WenJinMinchoP0-Regular.ttf` | 文津宋体 Plane 0，覆盖 CJK 基本区与部分扩展区 |
| `LXGW WenKai Mono Medium.ttf` | 霞鹜文楷等宽，中字重 |
| `last-resort-font-17.000.zip` | Last Resort 字体 v17，解压后使用 |
| `last-resort-font-18.000.zip` | Last Resort 字体 v18，解压后使用 |

> 压缩包需要先解压，取出里面的 `.ttf` 文件，再用「从文件添加字体」加载。

## 注意事项

1. **字体文件较大**：像文津宋体、Last Resort 这类全字库字体单个可能几十 MB，下载和加载需要一点时间。
2. **GitHub 上传限制**：网页上传单文件限制 25MB，超过的建议用 Git 命令行或 Git LFS 上传。
3. **iOS 上的字体选择**：从「文件」App 里选字体文件即可，不需要越狱或安装字体。
4. **添加到主屏幕**：Safari 打开网页后，分享 → 添加到主屏幕，可以当 App 一样使用。
5. **回退链过长会变慢**：虽然最多支持 256 个，但实际用几十个就够了，太多会拖慢渲染。
6. **Canvas 渲染**：所有字符都在 Canvas 上绘制，不依赖 DOM，速度快、内存占用低。

## 常见问题

### 为什么有些字显示成方框？

那个方框是 **Last Resort** 或字体内部的 `.notdef` 字形，表示当前回退链里没有任何字体覆盖这个码位。

### 为什么扫描到一半自动重启？

通常是字体太多、文件太大、毫秒太小，累积到 WebKit 内存上限了。解决办法：

- 把「毫秒」调大（比如 20~100）。
- 把「每段」调小（比如 1024）。
- 减少回退链里的字体数量。
- 分段扫描，不要一口气跑全范围。

### 为什么字体加载失败？

可能原因：

- 字体文件损坏。
- `.ttc` 集合文件浏览器支持不好，建议先拆成单个 `.ttf`。
- 文件太大，iOS 内存不够。

### 为什么网页里的字体和我本地的不一样？

`local()` 调用系统字体在不同浏览器 / 系统上支持程度不同。如果命中不了，就会走后面的回退链。所以最好用「从文件添加字体」明确加载。
